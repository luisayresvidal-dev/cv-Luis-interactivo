# CV Interactivo - Luis Antonio Ayres Vidal

Este proyecto es un Currículum Vitae interactivo desarrollado como parte de la evaluación del Módulo 2. Se centra en el uso de tecnologías web para crear una interfaz profesional, responsiva y funcional.

## Tecnologías Utilizadas
* **HTML5**: Estructura semántica (header, section, main, footer).
* **CSS3**: Estilos personalizados y diseño visual.
* **Bootstrap 5**: Framework para garantizar que el CV sea responsive (se vea bien en celulares y PC).
* **JavaScript & jQuery**: Implementación de la interactividad y lógica del sitio.

## Funcionalidades Interactivas (Eventos)
Para cumplir con los requerimientos, se implementaron los siguientes eventos:
1. **Modo Oscuro/Claro**: Cambio de tema visual mediante un botón en la Navbar.
2. **Validación de Formulario**: Validación en tiempo real del formato de correo electrónico.
3. **Interacción de Usuario**: Mensajes de confirmación al enviar el formulario de contacto.

## Información del Profesional
* **Perfil**: Técnico de Nivel Superior en Gastronomía Internacional (INACAP) con sólida experiencia en minería (Cerro Colorado).
* **Idiomas**: Francés avanzado e Inglés básico.
